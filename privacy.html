私人晨報日曆（Mac）隱私政策

本政策說明此個人用途日曆整合如何處理 Google 使用者資料。應用程式由帳號擁有人本人使用並控制。

取得的資料與用途

應用程式透過 Google 官方 OAuth 流程取得 calendar.events.owned.readonly 唯讀授權。程式實際只查詢本人主日曆中今天與未來三天的行程，使用行程識別資料、狀態、重複行程與更新版本資訊、名稱及起訖時間，整理今日安排及未來三天的提前確認提醒。

儲存與傳送

OAuth 憑證、背景授權及日曆快取保存在本人 Mac。專用授權檔僅允許本人作業系統帳號讀取。晨報準備資料與產生的內容會保存在本人 Mac，本機備份也可能包含這些資料；包含行程名稱與時間的晨報會依本人設定，送往本人指定的 Telegram 私人對話，由 Telegram 提供訊息服務。

日曆資料只用於本人要求的私人晨報功能。本程式不會將 Google 日曆資料送入 AI 模型或用於模型訓練，也不出售資料或用於廣告。Telegram 與網站代管平台的處理依各自的政策。本程式對 Google API 所取得資料的使用與轉移遵守 Google API Services User Data Policy，包括 Limited Use 要求。

保留與撤銷

最新日曆快取會隨成功更新替換；更新失敗時可能保留既有資料並標示過時。本機晨報紀錄及備份會保留至本人移除，Telegram 訊息由本人透過 Telegram 管理。本人可在 Google 帳戶第三方存取設定撤銷授權，以停止新的日曆資料讀取。授權到期或撤銷不會自動移除既有本機資料、備份或 Telegram 晨報。

公開說明網站

這個網站只提供功能說明與隱私政策，不提供日曆查詢或登入功能，也不載入廣告、分析或外部腳本。代管平台可能依其自身政策保留網站連線紀錄。
